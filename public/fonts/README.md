# Fuentes locales

DM Sans: body.woff2 y body-semibold.woff2.
Lora variable (400–700): lora-roman.woff2 y lora-italic.woff2.
Titulares regulares a 400 y énfasis en cursiva a 700. Los WOFF2 incluyen
caracteres latinos, acentos en español y puntuación; se sirven localmente.
Fuente: https://github.com/google/fonts/tree/main/ofl/lora

Cormorant Garamond: display.woff2 y display-italic.woff2 se conservan
como recursos de la versión anterior, pero ya no se cargan en la web.

Las licencias OFL se encuentran en docs/licenses/.
